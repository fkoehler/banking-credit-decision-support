# Five-minute demo script

1. Open the architecture index on GitHub and explain C4 as four zoom levels.
2. Start the local app and point out the synthetic-data banner.
3. As `advisor`, submit the prepared dentist financing example.
4. Explain that the PD is classical ML, while citations come from pgvector RAG.
5. Show `generationMode=template`: the local path needs no cloud key.
6. Switch to `reviewer`, inspect evidence and record an independent decision.
7. Close with the Azure deployment view and GitLab security gates.

Do not claim that the demo is production-ready or suitable for real decisions.
